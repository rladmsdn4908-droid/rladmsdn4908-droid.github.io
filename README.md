# 김은우 포트폴리오

화가 김은우의 포트폴리오 웹사이트입니다. GitHub Pages로 공개됩니다.

## 구성
- `index.html` 메인 · `works.html` 작품 · `exhibitions.html` 전시 · `text.html` 작업노트 · `cv.html` 이력 · `contact.html` 연락처
- `images/` 작품·전시 전경·드로잉 사진
- `dc.js` 페이지 동작(랜덤 배치, 갤러리, 작품 크게 보기, 이미지 저장 막기)
- `site.css` 휴대폰 화면 보정

## 수정하는 방법
작업용 원본은 Claude의 디자인 캔버스입니다. 원본에서 고친 뒤
`tools/build.py`로 이 폴더의 HTML을 다시 만들어 올립니다.

모든 작품 이미지의 저작권은 작가에게 있습니다.
